RESPUESTAS RÁPIDAS

Preguntas frecuentes

¿La disponibilidad mostrada es real y actualizada?

No. Los registros son ficticios y se incluyen únicamente para la práctica académica. Consulta directamente con el establecimiento para conocer disponibilidad real.

¿Es una página oficial del MINSA?

No. Es un prototipo universitario elaborado para demostrar conocimientos de desarrollo web e Interacción Humano-Computador.

¿Para qué sirven los filtros del dashboard?

Permiten explorar los indicadores y gráficos de una categoría o establecimiento específico, tomando como base los datos ficticios incluidos en el proyecto.

¿Dónde se guardan los registros?

El sistema utiliza una base de datos SQLite en el servidor y guarda una copia de respaldo externa en PostgreSQL. Así puede restaurar los usuarios, el inventario y los tratamientos de ejemplo después de reinicios. La base PostgreSQL gratuita vence el 14 de diciembre de 2026; antes de esa fecha se debe migrar o actualizar el plan para conservar los datos.

¿Cómo funciona la consulta de un paciente?

En esta demostración un Cuidador puede consultar el DNI vinculado a su cuenta y un Médico puede consultar el DNI que indique. El uso real requeriría consentimiento y verificación profesional.

¿Puedo utilizar esta aplicación para un tratamiento verdadero?

No. No es una historia clínica, no valida dosis y no ofrece información de stock verificable. Sigue siempre las indicaciones de un profesional sanitario.
